# Nameplate 0.60 (shipped with XI: Forever Offline)

Nameplate is by Shirk / HealsCodes and the BunnyBox Productions team: https://github.com/Shirk/Nameplate

Its newest version, 0.60 (2026-01-01, "support for the next version of the Ashita v4 beta"), is published on GitHub
only as source code; the only download there is v0.5.1.0d, which the current Ashita refuses to load. So
XI: Forever Offline ships this 0.60 build of the plugin (`plugins/Nameplate.dll`) with the kit.

License: GNU General Public License, version 3 (see https://www.gnu.org/licenses/gpl-3.0.en.html and the project's
LICENSE.md). The source code is at https://github.com/Shirk/Nameplate (version 0.60 = commit c379724 on main,
"was to be the 0.60 update"). Nothing in it was changed by us.

Use in game: `/load Nameplate`, then `/nameplate help`.
