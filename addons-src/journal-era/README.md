# Journal: era edits

[Journal](https://www.nexusmods.com/finalfantasy11/mods/44) by Kxteel (MIT) is downloaded by each player from Nexus Mods.
These edits make it show only what this server has (up to Treasures of Aht Urhgan). The launcher applies them:
Downloads tab > Journal > "Apply era edits". `patch.json` lists each change as find/replace; if Journal has changed
those lines in a newer version, nothing is applied. `era.lua` is ours: edit its two tables to change what counts as in-era.
